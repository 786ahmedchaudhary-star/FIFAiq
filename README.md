**FIFAiq**

A Jupyter notebook that explores a FIFA player dataset and applies a wide range of machine learning techniques to predict a player's overall rating (regression) and classify players as high-rated or not (classification). It also covers dimensionality reduction (PCA) and several clustering methods.

Includes both from-scratch implementations (gradient descent in NumPy) and scikit-learn models, so it works as a learning resource as well as an analysis.

Note: Fifa.csv is not generated by the notebook. Add the dataset file to the project root before running.

**📊 Dataset**
Rows: 18,539 players
Columns: 89 features
Content: player details such as name, age, nationality, club, height/weight, Overall and Potential ratings, market value, wage, release clause, preferred foot, skill moves, international reputation, and per-position ratings (e.g. LM Rating, CB Rating, GK Rating).
Targets used:
Regression: Overall (rating from 0 to 100)
Classification: Overall_Class = 1 if Overall >= 70, else 0

**⚙️ Preprocessing**
Checked duplicates and missing values
Kept numeric columns only
Filled missing numeric values with column means
70/30 train-test split (random_state=42)
Standardized features with StandardScaler (for models that need scaling)

**🔍 What's Inside**
1. Exploratory Data Analysis
Duplicate and null checks
Distribution of Overall ratings (count plot)
Age distribution (histogram)
Correlation heatmap of numeric features
2. Algorithms Implemented From Scratch (NumPy)
Model	Details
Linear Regression	Gradient descent on Age → Overall, with MSE and MAE tracking
Logistic Regression	Sigmoid + cross-entropy cost, gradient descent on Age → Overall_Class

Both include cost-convergence plots and a sample prediction (e.g. a 30-year-old player).

3. Regression Models (scikit-learn)

Linear Regression, Ridge, Lasso, SVR (linear kernel), MLP Regressor

4. Classification Models (scikit-learn)

Logistic Regression, Naive Bayes, KNN, Decision Tree, Random Forest, SVM (linear), MLP Classifier, AdaBoost

5. Dimensionality Reduction

PCA (10 components) compared against the full-feature models for both regression and classification.

6. Clustering

K-Means, Agglomerative Clustering, DBSCAN, and a Hierarchical Clustering dendrogram (Ward linkage).

**📝 Notes**
Features such as position ratings and Potential are strongly correlated with Overall, which helps explain the very high scores. Treat the results as a demonstration of the techniques rather than a deployable rating predictor.
Clustering plots use the first two feature columns for visualization only.
